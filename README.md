# AI Email Generator

AI-powered email generation application built using Python, Streamlit, and Google Gemini API.

## Features

- Generate professional emails
- Multiple email categories
- Tone selection
- Download generated emails
- User-friendly Streamlit interface

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- python-dotenv

## Installation

```bash
git clone <repo-url>
cd AI_Email_Generator

python -m venv .venv
pip install -r requirements.txt

streamlit run app.py
```
